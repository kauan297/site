MODO MOBILE — SEM PC E SEM MISTURAR CLIENTES

1 celular: inicie a LIVE no TikTok usando o modo de jogo/compartilhamento de tela, volte ao PalcoLive, conecte a LIVE e só depois abra o Roblox. O servidor continua ouvindo comentários e presentes mesmo com este painel em segundo plano.

2 celulares: é a opção mais estável. Celular B fica com este painel e conecta a LIVE. Toque em ENVIAR PALCO PARA OUTRO CELULAR e abra o link no Celular A, que roda/transmite o Roblox. Os dois usam a mesma sala exclusiva.

Cada cliente usa uma sala isolada, então pessoas diferentes podem usar o PalcoLive ao mesmo tempo sem misturar comentários. A transmissão de jogo/tela ainda depende dos recursos liberados pelo TikTok para a conta e o aparelho.

Configuração inicial

Configure uma vez e salve.

Toque em cada campo para escolher um presente. Se não encontrar o nome na lista, selecione Outro presente (digitar).

O nome deve corresponder ao que a conexão TikTok recebe. Se você mudar os presentes durante uma LIVE conectada, o PalcoLive vai reconectar para aplicar as mudanças.
